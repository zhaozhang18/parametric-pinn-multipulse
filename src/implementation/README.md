# Implementation sources

This directory contains the exact final scripts selected from the research workspace,
plus local dependencies required by those scripts. Historical suffixes such as
`v2`, `FINAL`, or `FIX` are intentionally retained here to preserve traceability to
the experiment outputs used in the manuscript.

For normal use, run the clean entry points in [`../../scripts`](../../scripts)
instead of invoking these long implementation filenames directly.

The only edits made during release preparation were documentation-only path/comment
cleanups. Numerical routines, model definitions, defaults, and experiment logic were
not refactored.
