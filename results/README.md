# Included results

- `paper_tables/` contains the six compact tables reported in the manuscript.
- `formal_summaries/` contains the small JSON/CSV summary files from the final
  evaluations used to audit those table values.

Per-sample `metrics_stream.csv` files, SSFM fields, and model checkpoints are omitted
from Git because of size. They are required for complete figure regeneration and
should be released separately as an archival asset.

The CNN forward summary corresponds to the final `universal_CNN_large_scaled` model used for the 0.96% value in Table II.
