# Code provenance

The released implementation was selected from the authors' experiment workspace and
mapped to the manuscript tables and figures. Some development and plotting scripts
were created or revised with assistance from generative-AI tools. All released files
remain the responsibility of the authors and should be reviewed and validated before
public publication.

The release preparation preserved the selected numerical implementation and added
only wrappers, documentation, deduplicated data copies, and nonfunctional comment/path
cleanups. `ORIGINAL_SOURCE_SELECTION.csv` records the original workspace paths and
file hashes.
